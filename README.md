# سوبيرات ريان - نظام إدارة متكامل

نظام متكامل لإدارة المبيعات والمشتريات والمخزون مع واجهة عربية سهلة الاستخدام.

## ✨ المميزات

- 🛒 **إدارة المبيعات**: تسجيل مبيعات، فواتير، عملاء
- 📦 **إدارة المشتريات**: تسجيل مشتريات، فواتير شراء، موردين
- 🏪 **إدارة المخزون**: متابعة الكميات، بحث، تصفية، تنبيهات النواقص
- 📊 **تقارير شاملة**: ملخصات، إحصائيات، حركة المخزون
- 🔍 **بحث ذكي**: بحث سريع عن المنتجات
- 🎤 **بحث صوتي**: دعم البحث بالصوت
- 📷 **الباركود**: مسح الباركود بالكاميرا
- 💾 **نسخ احتياطي**: تصدير واستيراد البيانات

## 🚀 كيفية التشغيل

1. قم بتحميل المشروع
2. افتح ملف `index.html` في المتصفح
3. ابدأ الاستخدام مباشرة

## 📁 هيكل المشروع

## 📱 الشريط السفلي

- **المبيعات** - لإدارة عمليات البيع
- **المشتريات** - لإدارة المشتريات
- **إضافة** (وسط) - لإضافة منتجات، عملاء، موردين
- **المخزن** - لعرض وإدارة المخزون
- **التقارير** - لعرض الإحصائيات

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- LocalStorage API
- SweetAlert2
- SheetJS (Excel)
- QuaggaJS (الباركود)
- Web Speech API (البحث الصوتي)
